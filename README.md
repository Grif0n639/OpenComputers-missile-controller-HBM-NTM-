# OpenComputers-missile-controller-HBM-NTM-

The missile control program from the HBM NTM mod. It is a single .lua file that you just need to run.

Download file (To download you need Internet Card):
wget https://raw.githubusercontent.com/Grif0n639/OpenComputers-missile-controller-HBM-NTM-/main/LaunchOS.lua

The program is multilingual (Russian and English), supports up to 4 launch pads connected to a PC.
You also need a Data Card for the program to work correctly

The program was written using ChatGPT
